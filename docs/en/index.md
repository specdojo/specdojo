# SpecDojo Documentation (English)

SpecDojo is an open-source toolkit that aims to make civic tech sustainable by reducing comprehension debt. Its kata provide patterns for reconstructing specifications and requirements from existing code and records, distinguishing evidence from assumptions, confirming them with people, and recording decisions.

SpecDojo organizes specifications and design upstream of other spec-driven development tools, supporting both new work and the recovery of knowledge from existing systems.

## Start here

- [[specdojo:quick-start-guide|Quick Start Guide]] — install SpecDojo, file your first item in the register, and run it with an AI agent.
- [[specdojo:civic-tech-starter-guide|Civic Tech Starter Guide]] — choose five starter kata, reconstruct knowledge from an existing system, and check assumptions with people.

## About the English edition

The English edition is being built in stages. Japanese is the source of truth; translated guides and kata record their Japanese source revision in frontmatter. This first stage includes the Quick Start, the Civic Tech Starter Guide, and the five starter kata above. Links to documents without an English version lead to the [Japanese edition](../ja/).

Kata language selection in the CLI and inclusion of English kata in the npm package are follow-up work. For now, read the English resources on this site; the CLI still uses Japanese kata and project paths such as `docs/ja/projects/`.
