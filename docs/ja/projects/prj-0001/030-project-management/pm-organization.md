# 組織定義

## 1. 組織モデル

社会課題を知る人、技術を担う人、継続参加者、AI Agent が、必要な責任を分担できる兼務型の組織とする。初期は1人の人間が複数ロールを兼務するが、個人開発を目的とはせず、CivicTech の参加者が増減・交代できる責任構造を先に定める。

| 責任領域       | 設計方針                                                    | 最終判断       | 実行・確認        |
| -------------- | ----------------------------------------------------------- | -------------- | ----------------- |
| 社会課題・価値 | 当事者、期待価値、優先順位、主要な合意を先に確認する        | `PO`           | `BA`、代表利用者  |
| 計画・調整     | 作業順序、課題・リスク、上限、参加・引き継ぎを管理する      | `PM`           | `PM`              |
| 実現・構造     | 文書体系、CLI、schema、生成・検証の責任を作業別に割り当てる | 各成果物の `A` | `ARC`, `DEV`      |
| 品質・公開     | 価値、検証結果、権利、個人情報、公開適性を確認する          | `PO`           | `BA`, `QE`, `OPS` |

AI Agent は記録、提案、作成、実装、検証を支援できるが、社会課題、期待価値、費用、受入、公開、継続の最終判断は行わない。

## 2. ロール・owner方針

- Role code と責務は [[prj-0001:pm-roles|ロール定義]] を正本とする。
- 実行主体と兼務は [[prj-0001:pm-members|メンバー定義]] を正本とする。
- Schedule の `owner` には Role code だけを使用し、個人名、member nickname、agent 名は使用しない。
- 初期 Launch Track では主に `PO`、`PM`、`BA`、`ARC`、`QE` を owner とし、実装・体験・運用の作業では必要に応じて `DEV`、`UX`、`OPS` を使用する。
- 兼務しても、作業責任 `R` と最終責任 `A` は [[prj-0001:pm-raci|RACI]] 上で区別する。

## 3. 正本と責任境界

| 情報                         | 正本                                                          |
| ---------------------------- | ------------------------------------------------------------- |
| Role code と責務             | [[prj-0001:pm-roles\|ロール定義]]                             |
| 実行主体と兼務               | [[prj-0001:pm-members\|メンバー定義]]                         |
| 成果物・主要判断の責任       | [[prj-0001:pm-raci\|RACI]]                                    |
| 関係者の期待・懸念・情報要求 | [[prj-0001:prj-stakeholder-register\|ステークホルダー登録簿]] |

本書には Role code 一覧、人物・agent 一覧、詳細な RACI を複製しない。

## 4. 見直し条件

当事者・協働組織・貢献者の参加、兼務による滞留、新しい実装・運用責任、公開範囲、AI Agent の権限が変わった場合に見直す。見直し時は、特定個人の無理な負担を前提にせず、必要な責任から分離し、人間の `PO` に主要な最終判断を残す。
