# 成功基準と受入条件

## 1. 判定対象と適用範囲

代表的なシビックテックプロジェクトを用いて、次の三つの価値仮説を判定する。

| 業務価値 ID | 業務価値                                                                 |
| ----------- | ------------------------------------------------------------------------ |
| BV-01       | 当事者の社会課題と期待価値が、実行可能な要求・仕様・試行成果につながる   |
| BV-02       | 資金と専門人材が限られていても、低い現金支出と許容可能な負荷で実現できる |
| BV-03       | 特定個人の無理な善意に依存せず、参加者が作業を分担・継承できる           |
| BV-04       | ソリューションと社会課題への取り組みが継続し、多様な参加者が関与できる   |

初期公開の GO / Not GO は SC-01〜SC-03 と AC-01〜AC-04 のすべてで判定する。SC-04〜SC-06 は公開後の価値検証であり、初期公開の合否には含めない。

「低コスト」は人の無償労働を意味しない。SpecDojo 自体の利用・ライセンス費、試行に追加で必要な現金支出、参加者別の作業時間、継続的な運用負荷を分けて判定する。

## 4. 判定手順と証跡

1. `PO` と `BA` が代表課題、当事者、期待価値、試行成果を定める。
2. `PO` と `PM` が、追加現金支出と参加者別作業時間の上限、対象期間、除外費用を試行前に承認する。
3. 代表参加者が SC-01〜SC-03 を実施し、`BA` が当事者価値、`PM` が費用・負荷、`ARC` が正本と再利用、`QE` が証跡を確認する。
4. 未達時は是正または期限付き例外を記録し、`PO` が GO / Not GO を判断する。
5. 公開後は `BA` が SC-04〜SC-06 を確認し、`PO` が改善方針を決める。
