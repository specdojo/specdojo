# 前提・制約・依存関係

本書は、[[prj-0001:prj-scope|プロジェクトスコープ]] で定めた SpecDojo の初期公開範囲を実行するために、成立するものとして置く条件、プロジェクトが守るべき限界、他者・意思決定・先行成果物への依存を整理する。対象範囲、対象外、境界の判断基準はプロジェクトスコープを正とし、本書では再掲しない。

## 1. 前提条件

社会課題と技術の接続、低コストな実現、無理のない継続に必要な成果物と代表試行は、[[prj-0001:prj-scope|プロジェクトスコープ]] の境界を正とする。本章では、その実行に必要な成立条件を扱う。

## 2. 制約事項

技術的中立性、人間の判断責任など、対象範囲に関する限界は [[prj-0001:prj-scope|プロジェクトスコープ]] の対象システム、スコープ外、境界の判断基準を正とする。本章では、スコープの実行に対して追加で課される予算・支出・公開情報上の限界を扱う。ACD-C01・ACD-C02・ACD-C04 は、[[prj-0001:prj-charter|プロジェクト憲章]] の「主要前提・制約」が認可判断に必要な範囲で示した内容を、監視方法・逸脱時対応まで含めて運用可能な形に展開したものである。公開情報の制約は憲章がスコープへ委譲しているが、スコープに除外条件と検知時の手順がないため ACD-C04 として登録する。

`PO` の承認を要する事項と承認証跡は、憲章の「権限委譲」と「本格実行開始の GO / Not GO 判断」を正とし、本書では行として登録しない（旧 ACD-C03 は同内容の再掲のため廃止した）。`PM` は決定・実行の前に `PO` の承認証跡を確認し、承認記録がなければ決定または実行を保留して `PO` にエスカレーションする。

## 3. 依存関係

本章では、プロジェクトの進行または初期公開が、他者から提供される判断、先行成果物、承認の成立を必要とする関係を扱う。プロジェクトスコープやプロジェクト憲章は本書の根拠文書であり、それらの文書自体をプロジェクトの依存先としては扱わない。

| 前提が崩れた     | 体制、判断・レビューの実施、公開判断                     | 利用できない人員と、停止する判断・レビュー                               | `PM` が影響範囲を整理し、代替担当を `PO` と協議する。                                                                        | 代替担当または判断時期を設定し、確保できるまで影響する作業を保留する。解消不能なら計画を再判断する。 |
| 制約に抵触した   | 費用、外部依存、運用責任、権限、公開適性                 | 支出・契約・決定・実行の有無と、承認証跡                                 | `PM` が未承認の活動を停止し、必要性と影響を整理して `PO` に報告する。                                                        | 未実施なら承認まで保留し、実施済みなら影響と是正策を記録して `PO` の判断を受ける。                   |

## 5. 監視・変更管理

- 本書は、スコープまたはプロジェクト憲章の変更、担当体制または作業環境の利用不能、予算・外部サービスに関する提案、`PJR-0120` または `PJR-0121` の決定・変更、初期公開範囲の決定、公開情報の混入の検知、GO / Not GO 判断の準備開始を契機に見直す。
- 前提の崩壊、制約への抵触、依存先の変更が生じた場合は、項目 ID、変化の内容、影響範囲、一次対応者、判断者、対応状況、再確認時期を [[prj-0001:pjr-index|プロジェクト登録簿]] に残す。`PM` は、発生済みの支障を課題、将来の不確実な影響をリスク、承認済み範囲・計画の変更提案を変更要求、`PO` の判断結果を決定記録として区別して登録する。課題・リスクは `PM` が対応状況を `PO` へ報告し、変更要求は `PO` の判断を受けて決定記録へ接続する。
- 各項目の所有者は成立状況と変化を確認し、`PM` はプロジェクト全体への影響を取りまとめる。スコープ、予算、公開、ライセンス、GO / Not GO の最終判断は `PO` が行う。
- 本書の改訂・廃止時は、`ARC` が文書構造・配置・命名・技術制約・参照資料の整合を、`QE` が受入条件と検証への影響を確認し、`PM` が必要な追従作業を Schedule と登録簿で追跡する。
