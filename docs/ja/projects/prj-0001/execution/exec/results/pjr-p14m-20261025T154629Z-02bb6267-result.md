## 4. 進め方

共有の `exec-defaults` に定義された親検証をプロジェクトごとに柔軟に制御するため、除外リスト形式の指定方法である `parent_validations_exclude` を導入しました。これにより、共有側の設定を複製することなく、特定の検証のみを無効化した上で、プロジェクト固有の検証を `run.parent_validations` で追記することが可能になります。実装にあたっては、設定スキーマの更新、型定義の追加、除外ロジックの組み込みを行い、単体テストおよび統合テストでその動作を検証しました。
