## 3. 申し送り

- ANSI 除去は ansi-regex 相当の実装で、OSC シーケンスの payload に空白を含む場合（例: 空白入りウィンドウタイトル）は payload テキストの一部が残ることがある。ただし ESC/BEL などの制御文字自体は必ず除去されるため、表・YAML の破損は起きない。より厳密な OSC 全除去が必要になった場合は `ANSI_ESCAPE` の OSC ブランチ拡張を検討する。
- `stripTerminalControlSequences` はソース中に生の制御文字（ESC/BEL や C0/C1 バイト）を含む正規表現リテラルを持つ。これは意図的（ansi-regex と同様）で、`ESLint` の `no-control-regex` はプロジェクト設定で無効のため警告は出ない。将来この regex を編集する際は、制御文字の混入・欠落に注意する。
