## 3. 申し送り

- 統合後に orchestrator が別の register 項目を `exec run --register` で1回実行し、統合完了まで確認するのが close 条件である。この確認は `requires_human` のまま残っている。
- `src/exec/` の中をさらに分けるかの判断は、evidence に結論がない。人間が判断または確認する必要がある。
- `lint:ts` に `max-lines-per-function` の警告が25件ある。今回の移動で追加されたものかは evidence から区別できない。
- 人の確認が必要: `post-integration orchestrator smoke check: exec run --register`（統合後にorchestratorが別のregister項目を1回実行し、統合完了まで確認するclose条件）

## 4. 進め方と実践の型の適用

codemod で exec の実装とテストを `src/exec/` と `tests/src/exec/` へ移し、import・パス参照・設計書・個票を更新した。build、help の前後比較、`catalog validate`、runner 検証で動作の維持を確認した。
