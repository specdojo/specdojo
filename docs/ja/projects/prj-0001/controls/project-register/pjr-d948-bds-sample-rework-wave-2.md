3 回目で迷った点と決めた内容:

- 翌週の扱い: 前回の締めの版と販売数を引き継いで前週比だけを直す案もあった。ただ、それでは「出力時点の最新の確認版を使う」規則に例外が生まれ、締め未確定の日を含む週では、引き継いだ値が記録と合わなくなる。そこで、続けて再出力する週も同じ規則で数え直し、販売数が変わる間は再出力を続けることにした。
