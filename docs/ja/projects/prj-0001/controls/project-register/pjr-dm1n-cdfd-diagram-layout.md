# PJR-DM1N CDFD の図を、種類ごとに囲み・担当のレーン・時系列で描く

## 1. 背景

CDFD の sample の図が分かりにくいため、全体概要は業務のまとまりの囲み、プロセスグループ別は担当ごとのレーンと受け渡しの番号、ユースケース別は D2 の sequence_diagram で描く

## 2. 入力

- indie の指摘（2026-11-28）: CDFD の図が分かりにくい。担当ごとのレーン、時系列の並び、業務のまとまりの囲みなどがないと頭に入らない。分かりにくいのは全部で、まず型の sample から直す
- 今の cdfd-d2-rulebook は direction: down と PDCA の順の並びを決め、コンテナはプロセスグループ別で関連プロセスを見た目でまとめるときだけ許し、全体概要でグループを囲むことを禁じている。担当のレーンと手順の番号の決まりはない
- 比べた案: A 担当ごとのレーン / B 時系列（ユースケース別は `sequence_diagram`、ほかは受け渡しの番号） / C 業務のまとまりの囲み。図の種類ごとに使い分ける推奨を indie が採った（2026-11-28）
- 担当 BA・期限 2026-12-31 は indie の指示（2026-11-28）

## 3. 検討した選択肢

| 選択肢 | 内容                                                                                             | 利点                         | 懸念                                           |
| ------ | ------------------------------------------------------------------------------------------------ | ---------------------------- | ---------------------------------------------- |
| A      | 担当（人・システム・外部主体）ごとに一番外のコンテナでレーンを作り、プロセスを担当のレーンに置く | 誰が何をするかが一目で分かる | レーンをまたぐ線が多いと込み入る               |
| B      | ユースケース別は D2 の `sequence_diagram` で描き、ほかの図は受け渡しに「1.」「2.」の番号を付ける | 順番がそのまま読める         | 厳密な DFD から手順の図に寄る                  |
| C      | 全体概要とプロセスグループ別で、業務のまとまりごとにコンテナで囲む                               | 全体の構造がつかみやすい     | 全体概要の今の禁止（グループを囲まない）を外す |

## 4. 決定内容

図の種類ごとに描き方を使い分ける。

| 図の種類           | 描き方                                                                               |
| ------------------ | ------------------------------------------------------------------------------------ |
| 全体概要           | C: 業務のまとまり（例: 仕入・在庫・販売）ごとにプロセスグループの代表ノードを囲む    |
| プロセスグループ別 | A と B: 担当ごとのレーンにプロセスを置き、受け渡しに手順の番号を付ける               |
| ユースケース別     | B: D2 の `sequence_diagram` で、参加する単位ごとの縦の線と、上から順の受け渡しで描く |

まず型の sample（`cdfd-overview-sample`・`cdfd-sample`・`cdfd-uc-sample`）と `cdfd-d2-rulebook` を直し、製品の CDFD は sample の形が決まってから PJR-T1D1 でそろえる。

## 5. 採択理由

- 今の図は PDCA の順の上から下の並びだけで、「誰が」と「どの順で」が図から読み取れず、頭に入らない（indie の指摘）。
- 図の種類で伝えたいことが違う。全体概要は構造、プロセスグループ別は担当と受け渡し、ユースケース別は順番を伝える。
