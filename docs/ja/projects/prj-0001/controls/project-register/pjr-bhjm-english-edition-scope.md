# PJR-BHJM 英語版の版と最初の範囲を決める

## 1. 背景

v0.10.0 の後の英語版を v0.11.0（マイナー）で出すか、最初にどこまで英語にするかを決める

## 2. 入力

- 利用者の依頼（2026-11-24）: v0.10.0 のリリースの後に英語版に着手したい
- オーケストレーターの推奨: 英語の kata や CLI の言語の選択を入れるならマイナー（v0.11.0）。README と文書サイトの文章だけなら版を上げないかパッチ
- v0.10.0 の後に機能追加を止める方針（PJR-6XYD）の例外として位置づける

## 3. 検討した選択肢

| 選択肢 | 内容                                                                                                                                   | 利点                                     | 懸念                                                 |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- | ---------------------------------------------------- |
| A      | v0.11.0 で、README・文書サイトの入口・クイックスタートと入門の型の組（PJR-BXYM）を英語にする。残りの型は日本語の人の確定の後に順に訳す | 早く英語の利用者に届き、訳し直しが少ない | 英語で使える型が最初は少ない                         |
| B      | v0.11.0 で、62 の型をまとめて英語にする                                                                                                | 英語で一通り使える                       | 規模が大きく、日本語を直すたびに英語も直すことになる |
| C      | README と文書サイトの英語の文章だけにし、版は上げない（またはパッチ）                                                                  | 手間が小さい                             | 英語の利用者が kata を使えない                       |
