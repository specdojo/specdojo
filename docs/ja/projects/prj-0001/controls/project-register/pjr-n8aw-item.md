# PJR-N8AW オーケストレーターの起票時対話サポート機能の追加

## 1. 概要

オーケストレーターを介した `register add` において、利用者がコマンドの引数（担当や期限など）を正確に把握していなくてもスムーズに起票できるようにする。
`orchestrator.md` のプロンプトを見直し、「不足している項目があれば推奨値を提示してヒアリングする」「起票後に自動生成される個票の _TODO_ 部分（概要や完了条件）について、会話の文脈から記述案を作成し、利用者の承認を得た上でファイルを自動更新する」といった行動ルールを追加する。

## 2. 完了条件

- [ ] `orchestrator.md` に対して、起票時の対話的サポート（不足項目のヒアリング・推奨値の提示）に関するルールが追記されていること。
- [ ] 起票後、自動生成された個票の `_TODO_` を埋めるための内容案をオーケストレーターが提示し、承認後にファイルを自動更新する振る舞い（プロンプト）が定義されていること。
- [ ] 実際にオーケストレーターと対話し、意図通りにヒアリングや提案が行われることが確認できていること。
