# PJR-0127 prj-overviewのプロジェクトWhyを明確化

## 1. 概要

後続文書の論点を安定させるため、対象者・課題・中心仮説・価値仮説・判断原則をプロジェクト概要の正本として明確化する

launch track では、対象を CivicTech に絞り、`prj-overview` の必要性を三つに明確化した後に、agent が生成する文書の論点と内容が改善した。後続成果物が共通の判断軸を参照できるよう、対象者、課題、中心仮説、価値仮説、判断原則をプロジェクトレベルの Why の正本として磨き込む。

## 2. 完了条件

- 対象者、解決すべき課題、取り組む必要性、中心仮説、価値仮説の関係が一貫して説明されている。
- 主要な判断原則が、各価値仮説を守るための判断軸として読み取れる。
- What / How に相当する記述が Why を越えて過度に具体化されず、後続成果物へ委譲する境界が明確である。
- 後続成果物が再掲せず参照できる、短く識別可能な中心仮説と価値仮説になっている。
- `prj-overview` に依存する既存成果物との矛盾および意図しない意味変更がないことを確認している。

## 4. 対応結果

- [[prj-0001:prj-overview|プロジェクト概要]]の対象者を、社会課題の当事者とシビックテックで実現・改善に関わる参加者の関係として明確化した。
- 課題と技術の断絶、実現費用の不足、善意への依存から、取り組む必要性、`CH-01`、`BV-01`〜`BV-04` へつながる論理関係を定義した。
- `BV-01`〜`BV-03` を CH-01 の初期成立に必要な価値仮説、`BV-04` をその先の中長期価値仮説として識別可能にした。
- 五つの判断原則に対応価値と判断軸を付け、当事者価値、総費用、参加負荷、継続可能性を確認する順序と棄却条件を明記した。
- What / How の詳細を後続成果物へ委譲し、既存の憲章、課題と解決アプローチ、スコープ、ステークホルダー登録簿、成功基準との矛盾および意図しない意味変更がないことを確認した。
