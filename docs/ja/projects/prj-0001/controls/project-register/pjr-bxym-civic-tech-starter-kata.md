# PJR-BXYM シビックテック向けの入門の型の組と導入ガイドを作る

## 1. 概要

小さなシビックテックのチームが最初に使う型の組を決め、理解の負債を減らすために何をどの順で残すかを示す導入ガイドを書く

## 2. 入力

- PJR-Y5RD の決定（2026-11-23）: kata による理解の負債の解消で、シビックテックを持続可能にすることを中核の位置づけにする

## 3. 完了条件

- シビックテックの小さなチーム（資金と専門人材が限られ、非エンジニアの当事者・市民・地域団体が加わる）が、最初に使う型の組（入門の型の組）を決める。候補は概要・課題と方針・業務仕様・機能一覧・判断の記録・登録簿など。選んだ型と、選ばなかった型を後で足す目安を表にする（PJR-Y5RD）。
- 入門の型の組で始める導入ガイドを、文書サイトのガイドとして書く。非エンジニアの参加者が読んで分かる言葉で、「理解の負債」を減らすために何をどの順で残すかを示す。既存のシステムから始める場合（復元）と、新しく作る場合の両方を扱う。
- 全部の型を求めないこと（Sustainable Participation）と、確認状態の目印（`_ASSUMPTION_`・`_UNDECIDED_`）の使い方をガイドに書く。
- `CHANGELOG.md` は変えない。個票の対応結果に「CHANGELOG に書く事項」の小節を作り、区分と行の文案を書く。影響がなければ「なし」と書く。
- 迷った点は executor が決め、決めた内容と理由を個票の対応結果と報告の `handoff` に書く。
- 保護された設定（`.specdojo/`・`.agents/`・`.claude/`・`.codex/`・`.opencode/`・`package.json` など）は変えない。
- `npm run lint:md`・`npm run lint:fm` を通し、親の検証を通す。

## 5. 対応結果

### 5.1. 実施内容

- [[specdojo:civic-tech-starter-guide|シビックテック入門ガイド]]（`status: draft`）を新設した。理解の負債と復元・確認状態・人の確定・記録の 4 段、入門の型の組、後で足す型の目安、新しく作る場合と既存のシステムから始める場合（復元）の残す順番、`_ASSUMPTION_`・`_UNDECIDED_` の使い方、全部の型を求めないこと（Sustainable Participation）を書いた。
- 入門の型の組は、プロジェクト概要・課題と解決アプローチ・ビジネスルール・システム化機能一覧・プロジェクト登録簿の 5 つとした。後で足す型は、用語集・ステークホルダー登録簿・プロジェクトスコープ・成功基準と受入条件・業務プロセス仕様・業務受入条件・システム化機能仕様・画面仕様・非機能要件・議事録とし、それぞれに足す目安を書いた。
- 文書サイトのサイドバー（`packages/docs-site/.vitepress/sidebar-config.ts` の「はじめに」）と、[[specdojo:specdojo-overview-guide|全体概要ガイド]] の `目的別の次の読み物`（作成する成果物を決める）に、このガイドを足した。

### 5.2. 判断と理由

- 業務仕様の入口はビジネスルールとし、業務プロセス仕様は後で足す型にした。シビックテックでは制度の計算・判定の正しさを当事者と確かめることが多く、ビジネスルールは書く量が少なくプログラムから復元しやすいためである。業務プロセス仕様の rulebook が `draft` であることも考えた。
- 判断の記録は独立した型にせず、登録簿の decision に含めた。決定記録（`dec`）の rulebook は非推奨で、登録簿が判断・やること・質問をまとめて持つためである。このため、候補の「判断の記録」と「登録簿」を 1 つの型として数え、組を 5 つにした。
- 用語集は入門の組から外し、後で足す型の先頭に置いた。非エンジニアの参加者には役立つが、最初から全員に書く手間を求めないためである（Sustainable Participation）。
- 復元の場合は、概要をプログラムから復元せず聞き取りから始める順にした。PJR-Y5RD のとおり、プログラムから「なぜ」は戻らないためである。
- 内容ごとに確認状態を表で記録する案（PJR-DZMV の案 D）は採否が決まっていないため、ガイドには書かず、既存の目印と「確かめた人と日付を本文に書く」運用だけを書いた。案 D を採った場合は、このガイドの `確認状態の目印を使う` を合わせて直す。
- ガイドは SpecDojo 本体の文書のため、prj-0001 の個票（PJR-Y5RD など）への参照は置かなかった。
- 「理解の負債」「Sustainable Participation」は SpecDojo 本体の文書ではこのガイドが初出である。用語集への追加はこの項目の範囲外とし、要るかは利用者が決める。
