# PJR-N4D0 同じ項目を何回か流すと、プロダクトの commit のタイトルがすべて同じになる

## 1. 課題内容

--force-restart や --resume で同じ項目を流し直すたびに、プロダクトの commit の 1 行目が項目のタイトルのままになり、履歴で回ごとの変更を区別できない。push の前に利用者が rebase の reword で直す必要がある
