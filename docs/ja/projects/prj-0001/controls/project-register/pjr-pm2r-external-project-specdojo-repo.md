# PJR-PM2R external_projects で SpecDojo のリポジトリへ起票を任せられない

## 1. 課題内容

external_projects の起票の委譲は相手の node_modules/.bin/specdojo を呼ぶが、SpecDojo 自身のリポジトリには npm install 後もこの実行ファイルがないため、利用者のリポジトリから本家へ起票できない。
