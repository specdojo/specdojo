# PJR-ABMP LP の会話例でオーケストレーターが内容を日本語で確かめる形にする

## 1. 概要

LP の「始める」の会話例（src/components/sections/GetStarted.astro）では、オーケストレーターがコマンドを見せて「次を実行します。よろしいですか。」と聞いている。specdojo 0.4.1 のオーケストレーター（prj-0001:PJR-C50G）は、何を・どんな内容で・何に影響するかを日本語で聞く形に変わったため、会話例をそれに合わせる。0.4.1 の公開後に変える

## 2. 完了条件

- specdojo 0.4.1 が npm に公開されてから着手する。
- `src/components/sections/GetStarted.astro` の会話例で、状態を変える操作の承認を求めるオーケストレーターの発言（起票、起票と一覧の作成、`repos` の追加、`exec run`、起票と close の 5 か所）を、何をするか・内容・影響を日本語で述べて「よろしいですか」と聞く形にする。聞き方は、公開された 0.4.1 のオーケストレーター本文の「承認の聞き方」に合わせる。
- コマンドを読者に見せる場面が要る場合は、会話の発言とは分けて「このとき実行されるコマンド」として示す。読者がオーケストレーターを使わずに同じ操作をできることは変えない。
- 結果の報告の発言（成功の報告、完了条件ごとの結果）は、今の内容のままでよい。
- 本体の README の「会話で操作する」の例と、聞き方が食い違わない。
- LP のリポジトリの検証（`npm run build` と、LP で定義された lint）が通る。
