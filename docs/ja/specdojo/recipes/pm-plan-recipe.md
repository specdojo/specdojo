# プロジェクト管理計画 作成レシピ

Project Management Plan Writing Recipe

価値検証に必要な管理・判断・証跡だけを、一つの軽量な管理計画へまとめる作り方です。

## 1. このレシピの使い方

- 概要、スコープ、成功基準から管理すべき価値と上限を抜き出します。
- 管理領域を一表へ統合し、判断ゲートと正本を接続します。
- 個別計画、RACI、Schedule、登録簿との重複を削除して仕上げます。
- 検証する価値と逸脱リスク（Why）、管理基準・上限・判断ゲート（What）、確認契機・逸脱時対応・責任（How）を整理し、成功基準 ID と各正本の証跡で追跡します（Trace）。個別計画の詳細は参照先へ委譲します。

## 2. 作成前に集める情報

| 項目       | 集める情報                                         |
| ---------- | -------------------------------------------------- |
| 価値と判定 | 成功基準 ID、受入条件 ID、判定時期                 |
| 境界       | スコープ内外、主要な変更条件                       |
| 費用・負荷 | 現金支出、作業時間、継続運用負荷の上限             |
| 実行管理   | Schedule、依存、主要成果物、登録簿                 |
| 判断       | 公開、例外、主要変更、継続・停止の判断者           |
| 正本       | 組織、RACI、品質、コミュニケーション、記録の参照先 |

## 3. 全体の作成手順

1. 管理目的を、検証する価値と対象期間で一文にします。
2. 軽量プロファイルを基本とし、拡張が必要な条件を決めます。
3. 管理対象ごとに基準・上限、確認契機、逸脱時対応、責任を一表へ書きます。
4. 人間の判断が必要なゲートだけを定義します。
5. Schedule、RACI、費用記録、品質証跡、登録簿の正本を示します。
6. 未決事項へ決定時期と判断者を付けます。
7. 他文書の一覧や詳細手順を削除します。

## 4. 各章の書き方

### 4.1. 管理目的と適用方針

- 何を成功とするか、どの期間を管理するかを確認します。
- 人と AI Agent の判断・実行境界を示します。
- 契約・監査・組織規模により個別計画が必要か判断します。

### 4.2. 統合管理方針

- 実際に管理する対象だけを行にします。
- 基準・上限が同じ行へ重複する場合は統合します。
- 費用は現金支出、作業時間、運用負荷を分けます。

### 4.3. 判断ゲートとエスカレーション

- 成功基準を複製せず、条件 ID を判断材料にします。
- 未達、上限超過、公開・権利上の問題など判断を上げる条件を書きます。
- 起案者、最終判断者、証跡を一組にします。

### 4.4. 正本・報告・見直し

- 情報ごとに正本を一つ決めます。
- 定期報告ではなく、判断・逸脱・作業節目を報告契機にできます。
- 変更時に更新する正本だけを示します。

## 5. 深掘り手順

1. 管理項目がどの価値または制約を守るか確認します。
2. 基準のない管理項目は削除するか基準を定めます。
3. 同じ責任・証跡を持つ行を統合します。
4. 個別計画へ委譲できる説明を削除します。

## 6. 良い例 / 悪い例

| 観点     | 良い例                           | 悪い例                       |
| -------- | -------------------------------- | ---------------------------- |
| 管理目的 | SC-01〜SC-03の代表試行を管理する | 一般的なPM項目を管理する     |
| コスト   | 現金支出と作業時間を別上限で確認 | 金額予算はないので管理しない |
| 正本     | 課題・リスクは登録簿を正とする   | 本文にも同じ一覧を持つ       |

## 7. レビュー観点

- 価値、スコープ、成功基準と対応しているか。
- 個別計画、RACI、Schedule、登録簿を再掲していないか。
- 判断条件、最終判断者、証跡が明確か。
- 費用と人の負荷を区別しているか。

## 8. 仕上げチェック

- 統合管理表、判断ゲート、正本がそろっている。
- 未決事項に決定時期と判断者がある。
- Agentに最終判断を委ねていない。
- 必要性のない章・表・関連文書一覧を残していない。
- 各管理対象について、価値またはリスク、基準・上限、確認契機、逸脱時対応、証跡が一続きで追跡できる。
