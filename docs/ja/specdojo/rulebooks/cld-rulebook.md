# 分類一覧（CLD）ドキュメント作成ルール（非推奨）

Deprecated Classification Definition Rulebook

この rulebook は非推奨です。略号 `cld` は概念クラス図（`ccd`）と紛れるため、後継の [[specdojo:cdt-rulebook|分類一覧（CDT）作成ルール]] へ移行しました。

## 1. 移行方針

- 新しい成果物は `cld-<term>` ではなく `cdt-<term>` として作成し、[[specdojo:cdt-rulebook|分類一覧作成ルール]] を参照します。
- 既存の `cld-*` 成果物やカタログ定義は、[[specdojo:id-and-file-naming-standard|ドキュメントIDおよびファイル命名標準]] の経路 B に従って `cdt-*` へ切り替えます。
