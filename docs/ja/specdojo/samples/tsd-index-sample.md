# 技術スタック一覧（TSD Index）サンプル

本書は、駄菓子屋きぬや販売管理システム（単一店舗・店頭タブレット 1 台）の本番環境・開発環境で採用する技術と担当責務の一覧である。対象は、販売・在庫・つけ管理を動かす実行時の技術と、開発・検証・文書化・運用監視を支える技術とする。構築・変更の作業前に前提となる技術と版の正本を確かめ、詳細 TSD や設定ファイルへたどるために使う。

## 2. 補足・詳細への導線

### 2.1. 全体の共通条件

- 「版・正本」列が `package.json` の技術は、メジャー版の制約を `package.json` で、実際に使う版を `package-lock.json` で確かめる。
- 一覧の版はメジャー版までを示す。パッチ版は一覧へ書かず、各正本で確かめる。
- 未採択の候補（例: 別の DB やホスティング）は一覧に載せず、登録簿の `decision` 個票で扱う。
- _UNDECIDED_: 店頭タブレットの OS と対応ブラウザ。決まった時点で区分「クライアント実行環境」の行を追加する。
