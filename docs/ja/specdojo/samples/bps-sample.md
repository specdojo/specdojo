# 補充依頼確定

在庫の補充基準割れを受け、店主代表が補充対象と依頼数量を決め、承認した補充依頼を仕入グループが参照できる状態で引き渡す。

## 1. 概要

- 業務目的: `cdfd-inventory` の補充判断（`P-06`）の業務目的を正本とし、本書はそのうち基準割れの判定結果から補充依頼の引渡しまでの流れを扱う。
- プロセス領域: 在庫グループ（`cdfd-inventory`）の補充判断（`P-06`）。同じ在庫グループの在庫確認（`P-05`）は販売・入荷数量から現在庫を確認できる状態に保つ流れで、本書は `P-05` が基準割れと判定した結果を受け取る側から扱う。現在庫の算出と基準との比較は `P-05` に残す。
- 対象者: 店主代表（判断・承認）、開発担当と同行レビュー担当（後続の機能設計と受入シナリオの入力に使う）
- 主担当: 店主代表
- 開始点: `T-01` の受領時点
- 終了点: 「出力」のいずれかが確定条件を満たした時点。承認済みで仕入グループへ未引渡しの補充依頼は終了点に当たらない。
- 対象外: 現在庫の算出（`P-05`）、仕入先の決定、発注の承認・送付、入荷検品、売場補充、既存の補充依頼の取消。グループ横断の順序は `cdfd-uc-replenishment`、仕入グループ内は `cdfd-purchasing` が正本

## 2. トリガー

| トリガー ID | 出来事                     | 発生元             | 受領情報                         | 開始条件                   | 不成立時の扱い |
| ----------- | -------------------------- | ------------------ | -------------------------------- | -------------------------- | -------------- |
| `T-01`      | 現在庫が補充基準を下回った | 在庫確認（`P-05`） | 商品、現在庫、補充基準、確認時刻 | 対象商品と現在庫を受領済み | 起動しない     |

## 3. 前提条件

- 店主代表が補充要否と依頼数量を判断できる（家族利用者代表の検出時も確定は店主代表）。判断できない間は起動せず、トリガーを保留する。
- 依頼数量は、`br-reorder-point` が判定する補充必要数を発注単位（仕入先が定める最小の発注数量）に合わせた数量とする。
- 未完了依頼は、仕入グループが入荷を記録していない補充依頼とする。そのうち数量を変えられるのは、仕入グループが発注内容を確定（`P-01-01`）する前のものに限る。

## 4. 入力

| 入力         | 入手元             | 利用目的                               | 必須 | 正本               |
| ------------ | ------------------ | -------------------------------------- | ---- | ------------------ |
| 対象商品     | 商品台帳           | 販売状態、継続取扱、補充基準、発注単位 | ○    | 商品台帳           |
| 現在庫       | 在庫記録           | 補充基準との差と補充必要数             | ○    | 在庫記録           |
| 未完了依頼   | 補充依頼           | 重複の確認と、数量を変えられるかの判断 | ○    | 補充依頼           |
| 補充判断基準 | `br-reorder-point` | 要否と補充必要数の判定規則             | ○    | `br-reorder-point` |

## 5. 処理

| ステップ ID | CDFD プロセス | 担当     | 入力                         | 活動・判断                                                          | 出力・完了条件                                                   | 例外           |
| ----------- | ------------- | -------- | ---------------------------- | ------------------------------------------------------------------- | ---------------------------------------------------------------- | -------------- |
| `S-01`      | `P-06`        | 店主代表 | 対象商品、現在庫             | 販売状態と継続取扱から補充判断の対象かを決める                      | 対象または補充不要が理由付きで確定                               | `E-01`         |
| `S-02`      | `P-06`        | 店主代表 | 対象商品、現在庫、未完了依頼 | `br-reorder-point` で判定時点の要否と依頼数量を決め、重複を確認する | 補充要否、依頼数量、根拠の BR ID、重複有無が確定                 | `E-02`、`E-04` |
| `S-03`      | `P-06`        | 店主代表 | 補充要の判定結果             | 判断根拠を添えて新規または修正済みの補充依頼を承認する              | 商品、数量、根拠、承認者、承認時刻付きの承認済み補充依頼がある   | `E-03`         |
| `S-04`      | `P-06`        | 店主代表 | 承認済みの補充依頼           | 仕入グループへ引き渡す                                              | 仕入グループが補充依頼を参照できることを確認し、引渡し時刻がある | `E-05`         |

分岐は判定の順に適用する。

- `S-01` で販売停止・終売と判断した場合、および `S-02` で判定時点の現在庫が基準以上の場合は、未完了依頼の有無にかかわらず補充不要記録を確定して終了する。既存依頼は取り消さず、記録に既存依頼の有無を残す。
- `S-02` で補充要かつ未完了依頼がある場合は `E-02` へ進む。補充要で未完了依頼がない場合は `S-03` へ進む。

## 6. 出力

| 出力         | 受け手       | 確定条件                                                           | 正本     | 後続処理                           |
| ------------ | ------------ | ------------------------------------------------------------------ | -------- | ---------------------------------- |
| 補充依頼     | 仕入グループ | `S-03` で承認され、`S-04` の完了条件を満たす                       | 補充依頼 | `H-01` で `P-01-01` 発注内容確定へ |
| 補充不要記録 | 店主代表     | 対象商品、理由、確認時刻、既存依頼の有無があり、新規依頼を作らない | 在庫記録 | 次回の販売・入荷後に再判定         |
| 重複不要記録 | 店主代表     | 対象商品、既存依頼、理由、確認時刻があり、新規依頼を作らない       | 補充依頼 | 既存依頼の処理を続ける             |

補充依頼は、新規の依頼と、`E-02` で数量を反映した修正済みの依頼のどちらも同じ確定条件で扱う。承認済みのまま `S-04` が完了していない依頼は保留記録で追い、出力として確定しない。

## 7. 例外・代替経路

| 例外 ID | 対象ステップ | 検出条件                                                       | 停止範囲       | 担当     | 処置                                                                                        | 再開条件・代替成果                                                                                 |
| ------- | ------------ | -------------------------------------------------------------- | -------------- | -------- | ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `E-01`  | `S-01`       | 「入力」の必須項目が不明                                       | `S-01` 以降    | 店主代表 | 不足項目、対象商品、確認依頼先を保留記録に残す                                              | 補完後に `S-01` から再開し、判定に応じて補充依頼・補充不要記録・重複不要記録のいずれか             |
| `E-02`  | `S-02`       | 補充要で、同じ商品に未完了依頼がある                           | 新規依頼の確定 | 店主代表 | 既存依頼が `P-01-01` 確定前なら数量を反映するか決める。確定後なら反映せず重複不要記録とする | 反映する場合は反映後の数量で `S-03` から再承認し `S-04` で渡し直す。しない場合は重複不要記録で終了 |
| `E-03`  | `S-03`       | 判断根拠を記録できない                                         | 承認以降       | 店主代表 | 補充依頼を承認せず、状況を保留記録に残す                                                    | 根拠の確認後に `S-03` から再開                                                                     |
| `E-04`  | `S-02`       | 未完了依頼を取得できない                                       | `S-02` 以降    | 店主代表 | 中断し、取得失敗を保留記録に残す                                                            | 取得後に `S-02` から再開し、判定に応じて補充依頼・補充不要記録・重複不要記録のいずれか             |
| `E-05`  | `S-04`       | 承認済みの補充依頼を仕入グループが参照できることを確認できない | 引渡し         | 店主代表 | 承認済み・未引渡しのまま状況を保留記録に残す                                                | 仕入グループが補充依頼を参照できることを確認した後、`S-04` から再開                                |

## 8. 検証・受入観点

| 観点               | 入力条件                                                    | 期待する業務成果                                                       | 確認可能な記録         |
| ------------------ | ----------------------------------------------------------- | ---------------------------------------------------------------------- | ---------------------- |
| 補充が必要         | 販売中、基準割れ、未完了依頼なし                            | 承認済みの補充依頼が一件、仕入グループが参照できる状態で引き渡される   | 補充依頼               |
| 補充が不要         | 販売停止・終売、または判定時に基準以上                      | 新規依頼がなく、補充不要理由と既存依頼の有無が残る                     | 補充不要記録           |
| 重複を数量へ反映   | 補充要、未完了依頼が `P-01-01` 確定前、店主代表が反映を選ぶ | 新規依頼はなく、修正済みの補充依頼が再承認され仕入グループへ渡り直す   | 補充依頼               |
| 重複で新規不要     | 補充要、未完了依頼が `P-01-01` 確定後、または反映しない     | 新規依頼がなく、既存依頼と理由が残る                                   | 重複不要記録           |
| 入力不足から再開   | `E-01` または `E-04` の検出条件                             | 保留記録が残り、補完後の判定に応じた三つの出力のいずれか一つが確定する | 保留記録、各出力の記録 |
| 根拠不足から再開   | `E-03` の検出条件                                           | 根拠確認まで承認されず、確認後に補充依頼が確定する                     | 保留記録、補充依頼     |
| 引渡し不可から再開 | `E-05` の検出条件                                           | 参照確認まで終了せず、確認後に引渡し時刻付きの補充依頼が確定する       | 保留記録、補充依頼     |
