# 商品区分

駄菓子屋販売管理システムにおける商品の業務分類および取扱区分を定義する。

## 1. 概要

- 業務目的: 取扱商品の特性に応じた税率適用、保管方法、発注判断の基準とするため、商品の業務大分類および取扱区分を定義する。
- 対象エンティティ: 商品（`product`）
- 主担当ロール: BA（ビジネスアナリスト）、PO（プロダクトオーナー）
- 利用者: DEV（実装・型チェック）、QE（税率計算・棚割りのテスト検証）

## 2. 分類定義

| 定義項目         | 内容                                                                                         |
| ---------------- | -------------------------------------------------------------------------------------------- |
| 対象エンティティ | 商品（`product`）                                                                            |
| 分類定義名       | 商品区分（`product_type`）                                                                   |
| 種別             | 業務分類                                                                                     |
| 正本参照（SSOT） | `src/types/product.ts#ProductType`                                                           |
| 説明             | 取扱商品の特性・保管要件・適用税率を決定する業務上の大分類。実装の型定義を正本として参照する |

## 3. 値の業務的意味と使い分け

値の一覧および識別子は TypeScript 型定義 `src/types/product.ts#ProductType` を正本とする。各値の業務上の意味、判断基準、使い分けは以下の通り。

| 値      | 分類名 | 業務上の意味と使い分け                                                                             |
| ------- | ------ | -------------------------------------------------------------------------------------------------- |
| `snack` | お菓子 | 間食用・駄菓子などの食品全般。賞味期限の管理を必須とし、軽減税率（8%）を適用する。常温棚で保管する |
| `toy`   | 玩具   | くじ、シール、カプセルトイ等の児童向け玩具類。賞味期限はなく標準税率（10%）を適用する              |
| `drink` | 飲料   | 清涼飲料水・瓶ジュース類。賞味期限管理を行い軽減税率（8%）を適用する。冷蔵ショーケースで保管する   |

### 3.1. 人が判断する業務分類（補足・スタンドアロン定義）

システム共通の型定義を持たず、店舗運営者（店主）が棚割りや仕入判断のために運用する業務上の限定区分。実装側に型がないためスタンドアロン形式で定義する。

| 値             | 分類名   | 表示名   | 説明・成立条件                                                                   |
| -------------- | -------- | -------- | -------------------------------------------------------------------------------- |
| `staple`       | 定番商品 | ★定番    | 年間を通して安定して売れ筋であり、欠品を防ぐべき基幹商品。発注点を高めに維持する |
| `seasonal`     | 季節商品 | 季節限定 | 花火（夏）、ハロウィン菓子（秋）など、特定季節のみ仕入れる商品。期末に売り切る   |
| `experimental` | 試験商品 | お試し   | 新規取扱の実験的商品。入荷後30日間の売れ行きを見て定番化するか判断する           |

## 4. 関連仕様との関係

- 業務データ辞書: `bdd-product.yaml` の `product` エンティティにおける `product_type` 属性の許容値として参照される。
- 画面仕様: 商品登録画面（`uis-product-registration.md`）の区分選択プルダウンの選択肢および税率自動判定に連動する。
- ビジネスルール: 在庫補充判断ルール（`br-reorder-point.md`）において、定番商品（`staple`）の優先度計算に使用する。
