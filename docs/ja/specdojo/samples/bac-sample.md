# 駄菓子屋きぬや 現金販売の業務受入条件

## 1. 概要

BAC を初めて作成する BA と、承認・設計・受入テストへ引き継ぐ担当者に向けた完成例である。構成と品質判定・検査・確定条件は [[specdojo:bac-rulebook|業務受入条件 作成ルール]] の「本文要件」に従う。rulebook・共通文脈が変わったときの追従は [[specdojo:sample-authoring-standard|Sample 記述標準]] の「運用ルール」に従う。

本書は、店主代表または家族利用者代表が現金販売を確定し、販売記録と在庫の変化を照合して店番を引き継げることを受入条件として定める。店主の記憶とノートへの転記に頼る負担を減らし、家族が担当しても同じ販売結果を確認できるようにする。

- 価値との対応: 販売と在庫の記録を照合する価値を BAC-01、販売できない購入を誤って確定せず引き継ぐ価値を BAC-02・BAC-03 で確認する。
- 利用場面・対象範囲: 単一店舗・端末1台で、購入する商品と数量をそろえ、請求額への合意と現金受領を経て、販売と在庫の記録を確認するまで。
- 対象外: つけ販売、キャッシュレス決済、返品、確定後の訂正、仕入れ、オフラインでの販売継続。
- 根拠: [[specdojo:prj-success-criteria-and-acceptance-criteria-sample|成功基準と受入条件]] の AC-01（販売記録が1件できる）と SC-06（未完了事項の引き継ぎメモ）を現金販売に限定して具体化する。販売確定の成立は [[specdojo:bes-sample|業務イベント: 店頭の現金会計の確定]] の「発生条件」に従う。在庫の反映と停止時の扱いを定める販売プロセス `bps-sales-order-flow` は未同梱のため、次の仮定で補う。

_ASSUMPTION_: 確定時は販売を1件記録し、販売数だけ在庫を減らす。在庫が足りない場合と入力が不足する場合は確定せず、不足を解消してから同じ購入内容の確認へ戻る。この仮定は `bps-sales-order-flow` が定まるまでの学習用の業務仮定であり、実店舗の承認済み仕様ではない。

_ASSUMPTION_: 未確定の購入は、分かっている商品・希望数量、不足情報、次に確認することを引き継ぎメモに残す。購入中止が合意された場合は中止を記し、再開対象から外す。販売記録・在庫記録・引き継ぎメモは論理的な証跡名であり、保存形式は本例で定めない。

次の表は、受入条件の関係者ごとに、確認・合意する内容を示す。

| 役割             | 確認・合意する内容                                                         |
| ---------------- | -------------------------------------------------------------------------- |
| 家族利用者代表   | 店主不在でも、販売記録・在庫・未確定の購入内容を照合して引き継げること     |
| 店主代表         | 販売確定の条件、販売を止める条件、停止後の次の行為を業務として承認すること |
| 同行レビュー担当 | 各シナリオの開始状態と確定後の記録から期待結果を確認できること             |
| 開発担当         | 業務条件を設計と動作確認へ引き継ぎ、入力項目と保存構造の正本を整えること   |

## 2. 受入条件

共通前提として、店番担当は店主代表または家族利用者代表とする。商品Aは販売可能な商品で、単価は最終的な販売価格30円、開始時の在庫は5個とする。各ケースは独立した開始状態で確認する。端末と記録は支障なく使える状態とする。計算方式・税区分・保存構造は本例では定めない。

### 2.1. BAC-01 現金販売を確定して記録を照合する

根拠: AC-01、現金会計の確定の「発生条件」と「事実データ」（商品明細・請求金額・受領金額・釣銭金額）。在庫の減少は概要の仮定。

#### 2.1.1. 前提

- 開始状態: 来店客と請求額を合意し、その金額の現金を受領している。
- 入力: 商品Aと在庫数以内の購入数量が確定している。

#### 2.1.2. 操作

- 店番担当が、商品と数量、請求額、受領額と釣銭がないことを確認して販売を確定する。

#### 2.1.3. 期待結果

- 状態・記録の変化: 各ケースとも、販売記録と在庫の変化が同じ販売に対応付いている。次の店番担当は、販売済みの購入と未確定の購入を区別できる。

次の表は、ケースごとの条件と、販売確定後に観測する期待結果を示す。

| ケース ID | 条件・入力                                                         | 期待結果（観測点）                                                   |
| --------- | ------------------------------------------------------------------ | -------------------------------------------------------------------- |
| C-01      | 家族利用者代表が商品Aを2個、請求額60円・受領額60円で販売する       | 商品A・数量2・販売額60円の販売記録が1件残り、在庫が5個から3個になる  |
| C-02      | 店主代表が商品Aを在庫と同じ5個、請求額150円・受領額150円で販売する | 商品A・数量5・販売額150円の販売記録が1件残り、在庫が5個から0個になる |

#### 2.1.4. 判定方法

確認者が各行の観測先で照合対象を確かめ、すべての行が期待結果と一致すれば BAC-01 を合格とする。

| 対応する期待結果・ケース ID | 確認者           | 確認時点     | 観測先（証跡）         | 照合対象                                       |
| --------------------------- | ---------------- | ------------ | ---------------------- | ---------------------------------------------- |
| C-01、C-02                  | 同行レビュー担当 | 販売確定直後 | 販売記録、在庫記録     | 商品・数量・金額・件数と、開始前後の在庫差分   |
| 状態・記録の変化            | 家族利用者代表   | 店番交代時   | 販売記録、引き継ぎメモ | 販売済みの内容と未確定の購入を区別して説明する |

### 2.2. BAC-02 在庫不足なら販売を確定せず確認へ戻る

根拠: 概要の在庫不足時の仮定、引き継ぎは SC-06。確定の記録がない間は現金会計の確定が発生しない（「発生条件」）。

#### 2.2.1. 前提

- 開始状態: 販売は未確定で、現金をまだ受領していない。
- 共通前提との差分: 商品Aの購入希望数は6個で、在庫5個を超えている。

#### 2.2.2. 操作

- 店番担当が、希望数量と在庫を照合して販売を進めようとする。

#### 2.2.3. 期待結果

- 停止時に確定しないもの: 販売は未確定のままで、販売記録は増えず、在庫は5個のままである。店番担当は対象商品と不足1個を確かめられる。店番担当は来店客へ不足を説明し、数量を変えるか購入を中止するかを確かめられる。
- 引き継ぎ: 店番交代時には、商品A・希望6個・不足1個・来店客への数量変更または中止の確認待ちを引き継ぎメモに残し、未確定の内容として次の担当へ渡せる。
- 数量変更に合意した場合: 来店客が2個への変更に合意したら、請求額と現金受領を確認してから BAC-01 の C-01 に相当する販売へ進む。希望数6個での販売記録は残らない。
- 購入中止に合意した場合: 引き継ぎメモを中止へ更新し、販売記録は追加せず在庫5個を維持する。

#### 2.2.4. 判定方法

数量変更と購入中止は、独立した開始状態で確認する。確認者が各行の観測先で照合対象を確かめ、すべての行が期待結果と一致すれば BAC-02 を合格とする。

| 対応する期待結果・ケース ID | 確認者           | 確認時点           | 観測先（証跡）                   | 照合対象                                  |
| --------------------------- | ---------------- | ------------------ | -------------------------------- | ----------------------------------------- |
| 停止時に確定しないもの      | 同行レビュー担当 | 停止直後           | 不足の表示、販売記録、在庫記録   | 希望数6個と、開始前の在庫5個・販売記録    |
| 引き継ぎ                    | 家族利用者代表   | 店番交代時         | 引き継ぎメモ                     | 対象商品・不足数・次の確認行為を説明する  |
| 数量変更に合意した場合      | 同行レビュー担当 | 合意後の販売確定時 | 引き継ぎメモ、販売記録、在庫記録 | 在庫3個・販売記録1件（C-01 相当）         |
| 購入中止に合意した場合      | 同行レビュー担当 | 中止の合意後       | 引き継ぎメモ、販売記録、在庫記録 | 中止の記載と、在庫5個・販売記録の追加なし |

### 2.3. BAC-03 必須情報が不足した購入を未確定のまま引き継ぐ

根拠: 現金会計の確定の「発生条件」2（商品明細と購入内容の確認）を満たさない場面。停止と引き継ぎは概要の入力不足時の仮定と SC-06。

#### 2.3.1. 前提

- 開始状態: 販売は未確定で、現金受領前である。
- 共通前提との差分: 期待結果のケース表（C-03・C-04）のとおり、販売に必要な商品または数量が分からない。

#### 2.3.2. 操作

- 店番担当が購入内容を確認し、不足があれば来店客または次の店番担当へ確認事項を伝える。

#### 2.3.3. 期待結果

- 停止時に確定しないもの: 両ケースで販売記録は増えず、在庫は5個のままである。
- 引き継ぎ: 店番担当は、引き継ぎメモに判明済みの情報と商品または数量の確認待ちを記し、確定済みの販売と区別して次の担当へ引き継げる。
- 再開条件: 不足が解消し商品A・数量2となった場合は、請求額と現金受領を確認してから BAC-01 の C-01 に相当する販売へ進める。不足中の内容を別の販売として残さない。

次の表は、不足する情報ごとの条件と、停止時に観測する期待結果を示す。

| ケース ID | 条件・入力                              | 期待結果（観測点）                                               |
| --------- | --------------------------------------- | ---------------------------------------------------------------- |
| C-03      | 数量2は分かるが、対象商品が特定できない | 対象商品の確認が必要と分かり、別の商品を推測して販売を確定しない |
| C-04      | 商品Aは分かるが、数量が不明である       | 数量の確認が必要と分かり、仮の数量で販売を確定しない             |

#### 2.3.4. 判定方法

確認者が各行の観測先で照合対象を確かめ、すべての行が期待結果と一致すれば BAC-03 を合格とする。

| 対応する期待結果・ケース ID        | 確認者           | 確認時点       | 観測先（証跡）     | 照合対象                                                     |
| ---------------------------------- | ---------------- | -------------- | ------------------ | ------------------------------------------------------------ |
| C-03、C-04、停止時に確定しないもの | 同行レビュー担当 | 停止時         | 販売記録、在庫記録 | 開始前の販売記録と在庫5個                                    |
| 引き継ぎ                           | 家族利用者代表   | 店番交代時     | 引き継ぎメモ       | 判明済みの情報・不足情報・次に確認すること・未確定であること |
| 再開条件                           | 同行レビュー担当 | 補完後の確定時 | 販売記録、在庫記録 | C-01 の期待値と、不足中の販売記録がないこと                  |
