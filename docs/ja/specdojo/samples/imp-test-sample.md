# 影響調査（テスト）サンプル

## 1. 目的と適用範囲

本書は、変更要求 `cr-2026-004`（バーコード会計とキャンペーン値引きの導入）が駄菓子屋の販売管理システムのテストへ与える影響を判断し、テストレベルとテスト観点の組ごとの変更要否・影響度・対応方針を `PO` が承認するための文書である。判定と記述は `QE`、計画と期限への影響の確認は `PM`、業務受入テストの観点の確認は `BA` が行う。

- 対象のテスト範囲: 単体テスト、結合テスト、業務受入テスト、回帰テスト。
- 対象外のテスト範囲: 性能テスト（1 日の会計件数が変わらないため。データ量への影響は `imp-data` で確認する）、つけ管理のテスト（つけ残高の計算仕様が変わらないため。業務への影響は `imp-business` で確認する）。
- 対象期間: 2026-05-07（テスト影響の判定開始）〜2026-05-28（受入判定日）。

_ASSUMPTION_: リリース予定日を 2026-06-01 とし、受入判定日はその営業日前の 2026-05-28 とする。

## 2. 変更要求の概要

- 背景: 夕方の混雑時に会計待ちが長くなるため、バーコード読取による会計とキャンペーン値引きを導入する。値引きの適用は売上集計と会計取消に波及し、既存のテストケースでは値引き後の金額を確認していない。
- 要求の要点: 値引き適用後の売上集計と会計取消を確認するテストケースを追加し、回帰テストを重点ケースに絞って受入判定日までに実行する。
- 狙い: 売上金額の誤りを本番へ流出させず、2026-05-28 の受入判定までに必要なテストを終える。

成功条件は次の 3 つとし、すべて達成した場合に受入確認を合格とする。

| 成功条件                                                    | 確認対象                 | 判定方法                                     |
| ----------------------------------------------------------- | ------------------------ | -------------------------------------------- |
| 追加した結合テスト 8 ケースと重点回帰 20 ケースが全件合格   | テスト結果レポート       | 2026-05-26 時点の合格件数が 28 件であること  |
| 更新した業務受入テストの判定項目がすべて合格                | 業務受入テストの判定記録 | 店主代表と家族利用者代表の同席で全項目が合格 |
| 重大度「高」（売上金額・つけ残高の誤り）の未解決欠陥が 0 件 | 欠陥一覧                 | 2026-05-28 の受入判定時点で該当欠陥が 0 件   |

## 3. 影響分析サマリ

評価観点は欠陥流出リスク、回帰範囲、実行コストの 3 つとし、観点ごとの高・中・低は次の条件で分ける。

| 評価観点       | 高                                         | 中                                             | 低                            |
| -------------- | ------------------------------------------ | ---------------------------------------------- | ----------------------------- |
| 欠陥流出リスク | 売上金額・つけ残高の誤りが本番で起こりうる | 表示や操作手順の誤りは起こるが会計は続けられる | 既存ケースで誤りを検出できる  |
| 回帰範囲       | 既存ケースの 30% 以上を再実行する          | 既存ケースの 10% 以上 30% 未満を再実行する     | 既存ケースの再実行が 10% 未満 |
| 実行コスト     | 追加・更新の工数が 3 人日以上              | 追加・更新の工数が 1 人日以上 3 人日未満       | 追加・更新の工数が 1 人日未満 |

集約規則: 観点ごとの判定のうち最も高いものを、その行の影響度とする。件数は「影響詳細一覧」の行を同じ規則で集計した。

| 影響度 | 件数 | 主な影響対象テスト         | 優先対応 |
| ------ | ---- | -------------------------- | -------- |
| 高     | 2    | 結合テスト、業務受入テスト | 要       |
| 中     | 1    | 回帰テスト                 | 要       |
| 低     | 1    | 単体テスト                 | 否       |

影響度「高」の 2 件のうち、結合テストを先に着手する。業務受入テストの判定項目は、結合テストで値引き後の金額が確定してから更新するためである。

| 影響対象テスト                             | 変更要否 | 影響度 | 対応方針 | 判断根拠                                                                                                                                                | 備考                                                                                                      |
| ------------------------------------------ | -------- | ------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 結合テスト／値引き適用後の売上集計と取消   | 要       | 高     | 実施     | 既存ケースに値引き後の金額の確認がない。欠陥流出リスク: 高（集計差異が本番で出る）、回帰範囲: 低、実行コスト: 中（2 人日）。最大値規則により高。        | 新規 8 ケース＝値引き種別 2（定額・定率）× 集計項目 2（売上合計・値引き合計）× 会計操作 2（確定・取消）。 |

## 5. 対応方針

| 影響度 | 対応項目                               | 期限       | 担当  | 前提条件                                                     |
| ------ | -------------------------------------- | ---------- | ----- | ------------------------------------------------------------ |
| 高     | 結合テストの新規 8 ケース追加・実行    | 2026-05-16 | `QE`  | 値引き条件の代表データセットの確定（未解決事項、2026-05-14） |
| 高     | 業務受入テストの判定項目とシナリオ更新 | 2026-05-20 | `BA`  | 店頭運用側の必須判定項目の確定（未解決事項、2026-05-13）     |
| 中     | 回帰テストの重点 20 ケース選定・実行   | 2026-05-24 | `QE`  | 重点ケースの優先順位基準の合意（未解決事項、2026-05-11）     |
| 低     | 単体テスト見送りの再評価               | 2026-07-31 | `DEV` | 実装差分レビューで値引き計算の分岐数を確認していること       |

- 回帰テストの代替（重点 20 ケースへの絞り込み）と単体テストの見送りは `PO` が判断した（決定記録 `PJR-T5D1`）。回帰テストは、重点ケースで欠陥が 1 件でも見つかれば残り 100 ケースを受入判定前に実行する。単体テストは、値引き計算の分岐が 3 件を超えたら 2026-07-31 までに再評価する。
- 受入確認: 2026-05-28 に `QE` が「変更要求の概要」の成功条件 3 つへ判定方法を当てはめ、全条件の達成を合格として `PO` の承認を受ける。未達の条件があれば、該当する行を「影響詳細一覧」と本表へ戻して期限を引き直す。
