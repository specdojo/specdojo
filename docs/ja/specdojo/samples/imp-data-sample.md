# 影響調査（データ）サンプル

## 1. 目的と適用範囲

本書は、変更要求 `cr-2026-004`（バーコード会計とキャンペーン値引きの導入）が駄菓子屋の販売管理システムのデータへ与える影響を判断し、データ対象ごとの変更要否・影響度・対応方針を、データの変更と移行に着手する前に決めるための文書である。業務への影響は [[specdojo:imp-business-sample|影響調査（業務）サンプル]] で判断済みであり、本書はその判断を前提に、波及するデータ構造・整合性・移行を扱う。I/F・テスト・運用への波及の詳細は、「影響詳細一覧」の備考に示す成果物へ委ねる。

- 対象のデータ領域: 商品マスタ、売上明細、キャンペーン適用履歴（新設）、価格履歴。
- 対象外のデータ領域: 顧客データとつけ残高（つけの計算仕様が変わらず、項目・件数とも変わらないため）、在庫数（バーコード会計でも減算の規則が変わらないため）。
- 対象期間: 2026-05-01（データ影響の判定開始）〜2026-07-31（移行後の月次照合の完了日）。

_ASSUMPTION_: 新しい項目でデータを記録し始める日（切替日）を、影響調査（テスト）と同じリリース予定日 2026-06-01 とする。

## 2. 変更要求の概要

- 背景: 夕方の混雑時に会計待ちが長いため、業務影響調査でバーコード読取による会計とキャンペーン値引きの導入が決まった。現行のデータには商品のバーコード値も値引きの理由もなく、日次締めで売上合計と現金残高が合わないときに原因を追えない。
- 要求の要点: 商品マスタにバーコード値を持たせ、売上明細に値引き額と値引き理由を記録し、適用したキャンペーンを履歴として残す。
- 狙い: 業務影響調査の成功条件（混雑時の 1 会計あたり平均 90 秒以内）を、会計時の照合失敗で崩さないこと。あわせて、値引き導入後も日次締めの売上合計を現金残高と突き合わせられる状態を保ち、店主の経験と記憶に頼らない締め作業を続けること。

成功条件は次の 3 つとし、すべて達成した場合に受入確認を合格とする。

| 成功条件                                                    | 確認対象                     | 判定方法                                                                                 |
| ----------------------------------------------------------- | ---------------------------- | ---------------------------------------------------------------------------------------- |
| 移行前後で、過去 3 か月分の日次売上合計の差額が 0 円        | 移行前後の日次締め帳票       | 移行テストで全営業日の売上合計を 1 日ずつ照合し、差額 0 円の日数が全日数と一致すること   |
| 売上上位 30 品目のバーコード照合失敗が 0 件                 | 会計時の照合エラー記録       | 切替日から 2 週間（2026-06-01〜2026-06-14）の照合エラーのうち、上位 30 品目の件数が 0 件 |
| 切替日以降の値引きのある売上明細で、値引き理由の欠落が 0 件 | 売上明細の整合性チェック結果 | 2026-06-01〜2026-06-30 の値引き額が 0 円でない明細のうち、値引き理由が空の件数が 0 件    |

## 3. 影響分析サマリ

影響度は、次の境界値を当てはめてから判定する。

- 許容停止時間: 営業時間中の停止は 0 分とし、移行作業は閉店後に行う。閉店後に使える時間の上限は _UNDECIDED_（店主代表が決める。未解決事項 `PJR-D4Q3`）。
- 補正で解消できる範囲: 移行後の日次売上合計の差額が 0 円に戻せること。戻せない差額が 1 件でも残れば「補正しても解消できない不整合」とみなす。
- 照合失敗の許容: 売上上位 30 品目では 0 件。それ以外の品目は手入力で会計を続けられるため、照合失敗を業務停止とみなさない。

整合性・可用性・移行難易度・利用者影響の 4 観点を、次の条件で判定する。

| 評価観点   | 高                                                             | 中                                                       | 低                         |
| ---------- | -------------------------------------------------------------- | -------------------------------------------------------- | -------------------------- |
| 整合性     | 補正しても解消できない、または締めの判断を誤らせる欠損・不整合 | 補正で解消できる不整合                                   | 現行データのままで整合する |
| 可用性     | 営業時間中の停止、または代替手段のない会計停止                 | 閉店後の停止で済み、営業時間中は手入力で会計を続けられる | 停止を伴わない             |
| 移行難易度 | 移行後に元のデータへ戻せない                                   | 既存データの変換・補正の手順が必要                       | 既存データの移行が不要     |
| 利用者影響 | 店番が会計を続けられない                                       | 店番の操作が変わる                                       | 現行の操作のまま続けられる |

集約規則: 観点ごとの判定のうち最も高いものを、その行の影響度とする。件数は「影響詳細一覧」の行を同じ規則で集計した。

| 影響度 | 件数 | 主な影響対象データ   | 優先対応 |
| ------ | ---- | -------------------- | -------- |
| 高     | 2    | 商品マスタ、売上明細 | 要       |
| 中     | 1    | キャンペーン適用履歴 | 要       |
| 低     | 1    | 価格履歴             | 否       |

影響度「高」の 2 件のうち、商品マスタを先に着手する。売上明細の値引き理由は会計時に読み取った商品へ付くため、商品のバーコード値が確定していないと移行テストの期待値を作れないためである。

## 5. 対応方針

| 影響度 | 対応項目                                         | 期限       | 担当  | 前提条件                                                    |
| ------ | ------------------------------------------------ | ---------- | ----- | ----------------------------------------------------------- |
| 高     | 商品マスタへのバーコード値追加と上位 30 品目登録 | 2026-05-15 | `DEV` | 上位 30 品目の一覧の確定（売上記録から抽出済み）            |
| 高     | 売上明細への値引き額・値引き理由の追加と移行     | 2026-05-22 | `DEV` | 値引き理由の区分の確定（未解決事項 `PJR-D4Q1`、2026-05-08） |
| 中     | キャンペーン適用履歴の新設                       | 2026-05-26 | `DEV` | 売上明細への値引き額の追加が終わっていること                |
| 低     | 価格履歴の見送りの再評価                         | 2026-07-31 | `BA`  | 月次照合で価格に起因する締めの差額件数を確認していること    |

- 見送り・代替の再評価条件: 価格履歴は、価格に起因する締めの差額が月 3 件を超えたら 2026-07-31 までに再評価する。キャンペーン適用履歴は、同じ日に 2 つ以上のキャンペーンが重なり、適用履歴だけでは値引き額の内訳を説明できない日が月 1 日でも出たら、対象商品の条件の記録を再評価する。

受入確認では、業務影響調査の各対象がデータ対象に欠落なく対応し、データ検証・移行テストで成功条件を満たすかを確かめる。2026-05-28 までに次の手順を行い、すべての合格条件を満たしたら受け入れてよいものとする。

| 確かめること                                     | 確認手順                                                                                                      | 合格条件                                                                                                    |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 業務影響の各対象に、対応するデータ対象の行がある | 業務影響調査の 4 業務（店頭販売、日次締め、在庫補充、ツケ管理）を「影響詳細一覧」の行と対象外の理由に照合する | 4 業務すべてが、いずれかの行か対象外の理由に対応している                                                    |
| 移行後も日次売上合計が変わらない                 | 移行テストで、過去 3 か月分の売上明細を移行し、移行前後の日次締め帳票を 1 日ずつ照合する                      | 全営業日で差額 0 円                                                                                         |
| 上位 30 品目をバーコードで会計できる             | 移行テストで、上位 30 品目の実物を 1 品ずつ読み取り、商品マスタの商品と一致するかを確かめる                   | 30 品目すべてが一致し、照合失敗 0 件                                                                        |
| 値引きのある明細に理由が付く                     | 結合テストで、定額・定率の値引きを各 1 件会計し、売上明細とキャンペーン適用履歴を確かめる                     | 値引き額 0 円でない明細のすべてに値引き理由があり、適用履歴の値引き額の合計が明細の値引き額の合計と一致する |

切替日以降の 2 つの成功条件（照合失敗 0 件、値引き理由の欠落 0 件）は、2026-06-14 と 2026-06-30 の時点で同じ合格条件により確かめる。
