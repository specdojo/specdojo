# 品質管理計画: 駄菓子屋きぬや 販売管理システム

## 1. 品質方針と適用範囲

品質は、文書が整っていることではなく、店主と家族が販売・在庫・つけの記録を正しく続けられ、追加負担を許容できることを中心に判定する。文書・実装・公開物の品質は、その価値を安全に実現するための条件として扱う。

## 2. 品質ゲート

| ゲート     | 品質観点                   | 合格条件                                           | 方法・証跡                        | 時期           | 確認者 / 承認者 |
| ---------- | -------------------------- | -------------------------------------------------- | --------------------------------- | -------------- | --------------- |
| 初期受入   | 基本業務を完了できる       | 販売、在庫、つけ管理の受入条件をすべて満たす       | シナリオ試験、結果記録            | リリース前     | QE / PO         |
| 短期利用   | 継続利用でき、負担が許容内 | 2週間記録を継続し、追加操作が1日10分以内           | 利用記録、利用者所感              | 試用終了時     | BA、QE / PO     |
| 技術・公開 | 安全に再現・公開できる     | 必須検証が成功し、個人情報・秘密情報を含まない     | lint、test、build、公開前レビュー | 変更時、公開前 | QE / PO         |
| 中期価値   | 記録が意思決定に役立つ     | 売れ筋、在庫、つけ状況の把握に利用された事例がある | 利用事例、振り返り記録            | 運用定着後     | BA / PO         |

中期価値ゲートは初期リリースの合否条件には含めず、継続判断に用いる。

## 3. レビューと証跡

| レビュー         | 主な観点                               | 実施者               | 証跡               |
| ---------------- | -------------------------------------- | -------------------- | ------------------ |
| 利用者レビュー   | 操作の理解、業務との一致、追加負担     | BA、店主、家族利用者 | 確認メモ、利用記録 |
| 成果物レビュー   | 目的・範囲・受入条件との整合、未決事項 | QE、関連ロール       | レビュー結果       |
| リリースレビュー | 品質ゲート、未解決事項、公開適性       | PM、QE               | 決定記録           |

証跡には、対象版、実施日、結果、未解決事項、再判定条件を残す。

## 4. 不適合と是正

| 区分                                   | 対応                                 | 再判定 | 記録先             |
| -------------------------------------- | ------------------------------------ | ------ | ------------------ |
| 軽微（誤字、説明不足）                 | 通常更新で修正する                   | QE     | レビュー結果       |
| 利用価値（操作不能、負担の上限超過）   | 原因を確認し、機能や手順を簡素化する | PO     | 課題、決定記録     |
| 技術（試験・build 失敗、データ不整合） | 影響範囲を含めて修正・再検証する     | QE     | 課題、検証結果     |
| 公開・安全（個人情報や秘密情報の混入） | 対象を隔離し、削除または匿名化する   | PO     | 課題、レビュー結果 |

重大な不適合は課題または変更要求として登録し、是正完了まで該当ゲートを通過させない。

## 5. 見直し条件と未決事項

成功基準、対象業務、利用者、検証方法、公開範囲が変わった場合に本計画を見直す。中期価値を確認する利用期間と対象件数は、2週間の店頭試用後に PO が決定する。
