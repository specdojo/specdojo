# 成功基準と受入条件: 駄菓子屋きぬや 販売管理システム

## 1. 判定対象と適用範囲

店頭販売、在庫、つけ管理の最小運用を対象とし、EC、複数店舗管理、本格会計連携、費用低減は対象外とする。初期リリースの受入は SC-01 と AC-01〜AC-04 のすべてを必須とし、SC-02〜SC-06 は合否に含めない。確認者の「両代表」は店主代表と家族利用者代表を指す。

| 業務価値 ID | 業務価値                                                 | 主な判定段階 |
| ----------- | -------------------------------------------------------- | ------------ |
| BV-01       | 店主と家族が同じ手順で販売・在庫・つけを記録・確認できる | 初期リリース |
| BV-02       | 日々の記録を負担なく継続できる                           | 短期         |
| BV-03       | 記録を仕入れと引き継ぎに使い、店主不在でも運営できる     | 中長期       |

## 2. 成功基準

| ID    | 対応する業務価値 | 条件                       | 判定基準                                                | 測定方法                                                         | 判定時期           | 確認者   |
| ----- | ---------------- | -------------------------- | ------------------------------------------------------- | ---------------------------------------------------------------- | ------------------ | -------- |
| SC-01 | BV-01            | 主要操作を迷わず完了できる | 販売記録・在庫確認・つけ残高確認を両代表が完了する      | 説明なしで代表シナリオを行い、所要時間・質問・支援・誤操作を記録 | 初期リリース受入時 | 両代表   |
| SC-02 | BV-02            | 記録を継続できる           | 営業日の90%以上で販売・在庫・つけの記録が残る           | 3種の記録有無を営業日ごとに集計                                  | 運用開始後2週間    | 店主代表 |
| SC-03 | BV-02            | 負担が小さい               | 1営業日の追加操作時間が合計10分以内                     | 記録・確認の所要時間を営業日ごとに測定                           | 運用開始後2週間    | 店主代表 |
| SC-04 | BV-03            | 人気商品の欠品を減らせる   | 対象商品の月間欠品回数が運用前1か月比で50%以上減る      | 日次記録の欠品を月単位で比較                                     | 運用開始後6か月    | 店主代表 |
| SC-05 | BV-03            | 在庫の無駄を減らせる       | 廃棄・値引き・長期滞留が年間換算で運用前から20%以上減る | 数量と金額の12か月実績を同じ定義のベースラインと比較             | 運用開始後12か月   | 店主代表 |
| SC-06 | BV-03            | 店主不在でも運営できる     | 不在の店番日の90%以上で必須記録と引き継ぎを完了         | 不在日ごとに記録と引き継ぎを確認                                 | 運用開始後6か月    | 両代表   |

## 3. 受入条件

| ID    | 対応する業務価値 | 種別       | 条件                             | 合格基準                                                                    | 証跡                       | 確認者   | 承認者   |
| ----- | ---------------- | ---------- | -------------------------------- | --------------------------------------------------------------------------- | -------------------------- | -------- | -------- |
| AC-01 | BV-01            | 利用者視点 | 販売を記録できる                 | 商品・数量・支払方法を確定すると販売記録が1件できる                         | 販売記録、操作結果         | 両代表   | 店主代表 |
| AC-02 | BV-01            | 利用者視点 | 在庫とつけ残高を確認できる       | 商品の在庫数と常連顧客のつけ残高を表示できる                                | 在庫一覧、つけ残高画面     | 両代表   | 店主代表 |
| AC-03 | BV-01            | 利用者視点 | 主要操作で重大な行き詰まりがない | SC-01 の代表シナリオで自力で回復できない事象が0件                           | SC-01 の測定記録           | 両代表   | 店主代表 |
| AC-04 | BV-01〜BV-03     | 技術的受入 | 確認結果を追跡できる             | スコープ・本書・操作メモが矛盾せず、結果ごとに条件 ID・確認日・確認者が残る | 文書照合記録、受入確認記録 | 開発担当 | 店主代表 |

## 4. 判定手順と証跡

確認者・承認者は各表に従い、結果は受入確認記録へ残す。

1. 初期リリース受入時に SC-01・AC-01〜AC-03 の代表シナリオと AC-04 の文書照合を行う。
2. 未達なら影響、是正内容、再確認の条件 ID と日を追記して再確認する。
3. 承認者が必須条件の結果を照合し、受入可否を判断する。
4. 運用開始後は SC-02〜SC-06 を判定時期に判定し、未達なら運用か改善方針を見直す。

## 5. 例外条件と未解決事項

| 論点                   | 判定への影響                   | 当面の扱い                                                        |
| ---------------------- | ------------------------------ | ----------------------------------------------------------------- |
| 人気商品の対象範囲     | SC-04 の測定。初期受入は進める | _UNDECIDED_: ベースライン測定開始前に対象商品と除外条件を固定する |
| オフライン時の記録方法 | 初期受入の対象外               | _UNDECIDED_: 初期運用開始前に運用方針を決め、受入条件を追加する   |
